What we build

calipercad builds open tools for people who design real, physical things — gears, enclosures, jigs, laser and CNC parts — and would rather type than click. One small Rust kernel with zero cargo dependencies does genuinely hard CAD: exact-integer 2D booleans, 3D mesh CSG, a 2D constraint solver, and an AI copilot that speaks the same command language you do. It's open core — a free, auditable foundation, with hosted and commercial editions on top for teams that need them.
